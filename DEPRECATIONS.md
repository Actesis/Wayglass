# Deprecations

Wayglass currently has no deprecated public API because no public version has been released.

Future deprecations must name the affected package and symbol, the first deprecated version, the
supported replacement, migration guidance, and the earliest permitted removal version. A warning
must be actionable and must not introduce import-time registration or another global side effect.
Removal follows the accepted SemVer and release-governance policy unless an approved safety or
security response requires immediate action.
