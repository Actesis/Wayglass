# Security policy

## Supported versions

No public Wayglass version exists yet. Each release record will name the exact supported package
versions and known limitations. Unreleased branches and private candidates do not carry a public
security-support promise.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull request. Use the
GitHub **Report a vulnerability** flow for `Actesis/Wayglass`; enabling and verifying private
vulnerability reporting is a prerequisite for making the repository public or publishing a package.
If that private reporting flow is unavailable, wait for the project to publish a verified private
contact rather than including sensitive details in a public channel.

Include the affected package and version or commit, impact, reproduction conditions, and the least
sensitive proof needed to understand the report. Do not include real credentials, personal data, or
third-party secrets. Maintainers will acknowledge and assess reports on a best-effort basis; a
release record may define a more specific response commitment only when the project can sustain it.
